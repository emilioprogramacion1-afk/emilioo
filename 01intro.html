BREVE HISTORIA DE HTML

HTML nació en 1989 gracias a Tim Berners-Lee, quien trabajaba en el CERN. Su objetivo era crear una forma sencilla de compartir y organizar información entre diferentes computadoras mediante Internet En 1991 se publicó la primera versión de HTML. Esta permitía crear documentos con texto y enlaces que conectaban unas páginas con otras, dando los primeros pasos para formar la World Wide Web. Con el paso de los años, HTML fue evolucionando y aparecieron nuevas versiones que permitían crear páginas más completas. Se agregaron elementos para incluir imágenes, tablas, formularios y diferentes tipos de contenido. En 1995 apareció HTML 2.0 como una versión más estable y posteriormente surgieron HTML 3.2 y HTML 4.01. Estas versiones ayudaron a establecer muchas de las características que todavía se utilizan para crear sitios web. Finalmente, HTML5 se convirtió en el estándar moderno de HTML Incorporó nuevas etiquetas y funciones para trabajar con multimedia y aplicaciones web, convirtiéndose en una herramienta fundamental para el desarrollo de páginas y sitios web actuales
