LISTA DE TERMINOS WEB

  • HTML - Lenguaje para crear paginas web
  • CSS - Lenguaje para diseñar paginas web
  • JavaScript - Lenguaje para agregar interactividad
  • HTTP - Protocolo de transferencia de hipertexto usado en la web
  • URL - Dirección única que identifica un recurso en internet
  • Servidor - Computadora que almacena y entrega información a otros equipos
  • Cliente - Dispositivo o programa que solicita servicios a un servidor
  • Navegador - Programa que permite visualizar páginas web
  • Base de datos - Sistema que almacena y organiza información de forma estructurada
  • Frontend - Parte visual de una aplicación con la que interactúa el usuario
