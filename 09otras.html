```html OTRAS ETIQUETAS HTML

OTRAS ETIQUETAS HTML

REGRESAR

1. <details>

Descripción: Crea una sección que el usuario puede abrir y cerrar para mostrar información adicional.

Ejemplo:

Ver información

Este texto aparece cuando se abre la sección.

2. <summary>

Descripción: Define el título visible de una sección creada con la etiqueta details.

Ejemplo:

¿Qué es HTML?

HTML es un lenguaje de marcado utilizado para crear páginas web.

3. <dialog>

Descripción: Crea una ventana de diálogo o cuadro emergente dentro de una página web.

Ejemplo:

Hola, esta es una ventana de diálogo.

4. <blockquote>

Descripción: Se utiliza para colocar una cita o texto tomado de otra fuente.

Ejemplo:

La educación es una de las herramientas más importantes para aprender.

5. <ins>

Descripción: Indica que una parte del texto ha sido agregada o insertada recientemente.

Ejemplo:

La página fue actualizada con nueva información.

6. <del>

Descripción: Indica que una parte del texto ha sido eliminada o ya no es válida.

Ejemplo:

Precio anterior: $500 Precio actual: $350

7. <small>

Descripción: Representa texto de menor importancia, como notas, aclaraciones o información adicional.

Ejemplo:

Página creada para una práctica de HTML. Última actualización: 23 de septiembre de 2026.

8. <kbd>

Descripción: Representa una tecla o combinación de teclas del teclado.

Ejemplo:

Para copiar utiliza Ctrl + C.

9. <samp>

Descripción: Representa una salida o resultado producido por un programa.

Ejemplo:

Resultado: Archivo guardado correctamente.

10. <var>

Descripción: Representa una variable matemática o una variable utilizada en programación.

Ejemplo:

La fórmula es: x + 5 = 10

11. <dfn>

Descripción: Indica el término que se está definiendo dentro de un texto.

Ejemplo:

HTML es un lenguaje de marcado utilizado para crear páginas web.

12. <bdi>

Descripción: Aísla una parte del texto que puede tener una dirección diferente al resto del contenido.

Ejemplo:

Usuario: محمد

13. <bdo>

Descripción: Permite cambiar la dirección en la que se muestra un texto.

Ejemplo:

Este texto aparece de derecha a izquierda.

14. <ruby>

Descripción: Se utiliza para colocar anotaciones o pronunciaciones sobre determinados caracteres.

Ejemplo:

漢字 かんじ

15. <rt>

Descripción: Contiene la pronunciación o anotación que aparece dentro de una etiqueta ruby.

Ejemplo:

東京 とうきょう

16. <rp>

Descripción: Proporciona texto alternativo para navegadores que no soportan correctamente las anotaciones ruby.

Ejemplo:

漢 ( kan )

17. <wbr>

Descripción: Indica un posible punto donde una palabra o texto puede dividirse cuando no hay suficiente espacio.

Ejemplo:

supercomputadora

18. <meter>

Descripción: Representa una medida dentro de un rango conocido.

Ejemplo:

Nivel de batería: 70%

19. <progress>

Descripción: Muestra el progreso de una tarea que se está realizando.

Ejemplo:

Descargando: 70%

20. <time>

Descripción: Representa una fecha u hora específica.

Ejemplo:

La práctica fue realizada el 23 de septiembre de 2026.

FIN DE LAS 20 ETIQUETAS

```
